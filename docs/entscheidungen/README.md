# Entscheidungsregister

Materielle Projektentscheide werden ab AP3 als einzelne Markdown-Dateien geführt. Die Dateinamen folgen dem Muster:

`DEC-JJJJ-NNN-kurztitel.md`

Jede Datei enthält mindestens:

- ID und Status
- Entscheidungsdatum
- Klasse und verantwortliche Person
- Ausgangslage und Entscheidungsfrage
- geprüfte Optionen
- Entscheid und Begründung
- Folgen, Risiken und Rückabwicklung
- Nachweise wie Quellen, Issues, Tests oder Prototypen
- allfälligen ersetzten oder nachfolgenden Entscheid

Frühere Entscheide werden nicht überschrieben oder gelöscht. Ein späterer Entscheid verweist auf den ersetzten Datensatz.
