# Lizenzzuordnung

Dieses Repository verwendet je nach Werktyp unterschiedliche Lizenzen.

| Werktyp | Standardlizenz | SPDX-Kennung |
| --- | --- | --- |
| Programmcode, Buildskripte und technische Konfiguration | GNU Affero General Public License Version 3 | `AGPL-3.0-only` |
| Eigene Dokumentation | Creative Commons Namensnennung, Weitergabe unter gleichen Bedingungen 4.0 International | `CC-BY-SA-4.0` |
| Kuratierte Regel- und Kalenderdaten | CC BY-SA 4.0, soweit rechtlich zulässig | `CC-BY-SA-4.0` |

Der vollständige AGPL-Text steht in der Datei `LICENSE`. Der vollständige CC-BY-SA-4.0-Text steht in `LICENSES/CC-BY-SA-4.0.txt`.

## Grenzen

Diese Zuordnung erfasst nur Rechte, über die die jeweilige beitragende oder veröffentlichende Person verfügen darf. Sie lizenziert insbesondere folgende Inhalte nicht neu:

- amtliche Erlasstexte und amtliche Publikationen
- Inhalte, Daten oder Abbildungen Dritter
- zitierte Quellen
- Marken, Logos und Kennzeichen
- Personendaten oder vertrauliche Informationen

Abweichende Hinweise in einzelnen Dateien, Datensätzen oder Quellenverzeichnissen gehen dieser Standardzuordnung vor. Herkunft, Quellenbedingungen und allfällige Nutzungseinschränkungen werden bei kuratierten Daten pro Datensatz dokumentiert.
