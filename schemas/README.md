# Datenschemata

Hier werden die maschinenlesbaren Schemata für Rechtsprofile, Feiertage, Fristenstillstände, Datenreleases und Prüfsummen geführt.

Die Schemata werden in AP5 festgelegt. Unbekannte Regeltypen sollen später abgewiesen werden. Änderungen an einem veröffentlichten Schema benötigen eine dokumentierte Migrations- und Kompatibilitätsentscheidung.
